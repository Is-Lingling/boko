# 个人博客

一个自托管的个人博客，集文章阅读、个人主页、动态社区、内容管理于一体。下面是它的功能一览（不含实现细节）。

## 核心功能

### 文章
- **文章阅读**：支持正文排版、目录导航与右侧栏（文章页专属），阅读体验适配宽屏与窄屏。
- **文章列表**：首页/文章页提供置顶推荐轮播、按时间/热度排序、标签筛选。
- **搜索**：顶部全局搜索框，按关键词检索文章。
- **标签与分类**：文章可按标签、分类组织，便于浏览与归档。
- **评论**：文章支持读者评论互动。
- **导出**：文章内容可导出。

### 首页（个人主页）
- 以「个人简历 / 自我介绍」形式呈现：头像、昵称、简介、座右铭、联系方式、技能、项目经历等模块。
- 内容由后台数据动态渲染，便于维护更新。

### 动态（个人空间）
- 类似朋友圈 / 动态流的个人空间，展示博主发布的动态。
- 点击左侧头像或「动态」导航进入。

### 内容管理（控制台）
- **控制台**：管理员可集中管理文章、动态等内容。
- **回收站**：已删除内容进入回收站，可查看与恢复。
- **图床**：图片上传与管理。
- **文件管理**：站点文件的管理入口。
- **编辑器**：撰写与编辑文章。

### 账户与权限
- **登录**：点击 Logo 以弹窗形式登录（移动端同样为弹窗，不跳转整页）。
- **管理员专属**：登录后显示「退出管理」与左侧「管理」板块；未登录时不暴露管理功能。

### 外观与体验
- **主题切换**：一键在浅色 / 暗黑模式间切换，选择会记住并保持。
- **音乐播放器**：内置轻量音乐播放器，支持播放/暂停、下一首、歌单列表与进度调节。
- **响应式布局**：
  - 桌面（≥1024px）：左栏导航 + 主内容 + 文章页右侧栏的完整三栏布局。
  - 平板（768–1023px）：左栏成列、右栏自动隐藏。
  - 手机（<768px）：单栏布局，左侧导航收起为**抽屉式菜单**（点击汉堡按钮展开），登录等操作为弹窗，内容不裁切、不溢出。
