# 修改记录

本文件记录本仓库历次较重要的功能与界面修改。按时间倒序排列，每条标注修改内容、涉及文件与验证方式。

## 2026-08-20 移动端响应式布局修复（R1–R8）

本轮集中处理「多端显示异常」与「移动端布局」问题，覆盖首页、文章、动态、控制台、回收站等页面。

### R8 · 移动端首页/动态/控制台/回收站右侧空白
- **问题**：手机端（<768px）上述页面右侧出现约一半的空白区域，内容被挤压到左侧窄条。
- **根因**：`article-unified.css` 在 `≤1100px` 把 `.yinying` 网格定义为 `200px 1fr 260px`（三栏），而移动端 `.box1`/`.box3` 为 `display:none`；按 CSS Grid 自动放置规则，可见的 `.box2` 落入第一个 `200px` 轨道，剩余 `1fr`/`260px` 轨道留空 → 视觉上的「右半空白」。
- **修复**（`css/responsive.css`，仅作用于 `≤767px`，不影响桌面端）：
  - `.yinying { grid-template-columns: 1fr !important; max-width: 100% !important; }` 强制单栏。
  - `.box2, .box2 * { min-width: 0; }` 允许内部元素收缩，避免被固定宽度撑破容器。
  - 简历卡片（hero / 简介 / 标签 / CTA / 关于 / 项目）补充 `overflow-wrap/word-break/white-space:normal` 与 `flex-wrap`，并强制 hero 与简介在移动端纵向堆叠居中，防止标题/标签/按钮溢出。
- **验证**：用无头 Chrome + `getBoundingClientRect()` 数值测量（截图因模型不支持图片故不可信，改用数值真值）。
  - 移动宽度（≤767 断点，实测 vw=500）：`.yinying` 计算为单栏 `476px`，`.box1`/`.box3` 宽 `0`（隐藏），`.box2` 及内部所有块（heroCard/title/cta/aboutGrid 等）右边界均 `< 视口宽`，**无溢出、无右半空白**。
  - 桌面宽度（1280）：保持 3 栏/2 栏设计（首页等视图按设计隐藏右侧栏），**无回退**。

### R7 · 动态页多出文章页右侧栏
- **问题**：动态（space）页错误地出现了文章详情页才有的右侧栏。
- **修复**：动态等非详情视图通过 `js/ui.js` 的 `hide-right-sidebar` 机制隐藏全局右侧栏（`.box3`），与首页/控制台/回收站/图床/文件管理一致。

### R6 · 动态页日历随页面缩小隐藏
- **问题**：网页端动态页的右侧日历在窗口变窄时不应一直占宽。
- **修复**：在 `≤1100px` 隐藏 space 视图右侧栏（日历），行为对齐文章页右侧栏。

### R5 · 移动端右侧裁切 + 登录改为弹窗
- **修复**（`css/responsive.css`）：
  - 首页/动态/控制台/回收站在移动端改为单栏，取消横向裁切。
  - 点击 Logo 触发的登录改为**弹窗（modal）**形式，而非整页跳转。

### R4 · 动态日历可隐藏
- 动态页右侧日历支持在窄屏/按需隐藏（与 R6 一并落地）。

### R3 · 主题设置入库
- 将「主题（浅色/暗黑）」从前端临时状态改为**持久化到数据库**，刷新后保持。

### R2 · 静态页转动态渲染
- 首页简历等内容由静态 HTML 改为由数据**动态渲染**，便于后台维护。

### R1 · 跨设备文章显示异常
- 修复同一篇文章在桌面/移动端显示不一致的问题。

### 涉及文件
- `css/responsive.css`（主要）
- `css/article-unified.css`、`css/index.css`（分析根因，未改其结构）
- `js/ui.js`（右侧栏显隐、视图切换）
- `index.html`（样式加载顺序：index.css → article-unified.css → responsive.css，responsive.css 最后加载以兜底）

---

## 约定
- 样式加载顺序：`index.html` 依次引入 `index.css` → `article-unified.css` → `responsive.css`，`responsive.css` 置于最后，对同等特异性的响应式规则起最终兜底作用。
- 移动端断点：`<768px` 为手机单栏；`768–1023px` 为平板（左栏成列、右栏隐藏）；`≥1024px` 为桌面完整布局。
